Overview

About the Project

This project involved a full revamp of GAFI's existing investment facilitation platform — replacing the ageing legacy system with a modern, maintainable architecture built on .NET Core, Angular, and SQL Server. The goal was to deliver a faster, more reliable, and future-proof platform that continues to serve foreign and domestic investors looking to establish businesses in Egypt, while significantly improving UX and system performance.

My Role

Responsibilities

As Engineering Specialist, I led the technical migration from legacy components to modern .NET, redesigned key backend modules for better performance and scalability, and collaborated with frontend developers to deliver an improved Angular-based user interface. I was responsible for database schema optimisation, API design, and ensuring a smooth transition with zero downtime for existing users.
