Overview

About the Project

First Abu Dhabi Bank (FAB) is the UAE's largest bank by total assets, managing over AED 1.2 trillion across 20 countries. This project involved developing and enhancing internal and customer-facing digital banking systems for FAB using the OutSystems low-code platform — delivering rapid, enterprise-grade feature development with strict security and compliance requirements typical of large financial institutions.

My Role

Responsibilities

As Software Engineering Specialist, I led the design and implementation of new features on the OutSystems platform, coordinating with FAB's internal teams to ensure alignment with banking standards and compliance requirements. I managed debugging pipelines, conducted code reviews, and ensured that all deliverables met enterprise security, performance, and scalability benchmarks.

Challenges

Technical Challenges

Banking Security Standards

Meeting the UAE Central Bank's stringent compliance requirements demanded rigorous implementation of MFA, data encryption, and audit logging across all modules.

OutSystems at Scale

Leveraging OutSystems' low-code platform effectively for enterprise banking — balancing rapid delivery with performance, security, and maintainability at FAB's scale.

Legacy System Integration

Integrating with FAB's existing core banking systems required detailed API mapping, transformation logic, and extensive end-to-end testing to ensure data integrity.
